# ข้อสอบจริงและสูตรลัด: บทที่ 10 ทฤษฎีกราฟ (Graph Theory Exam Traps & Formula Leaks)

เอกสารรวบรวมแนวข้อสอบจริง จุดลวง (Traps) ที่ทำให้นักศึกษาได้ 0 คะแนน และสูตรลัดคำนวณหน่วยความจำจากการบรรยายสดของ **ดร.ประดิษฐ์ พิทักษ์เสถียรกุล** เมื่อวันที่ 23 กันยายน 2569

## 1. จุดลวงขั้นวิกฤตที่ได้ "0 คะแนนทันที" (Zero-Point Exam Traps)

### กับดักที่ 1: การเขียน Path (ทางเดิน)
- **โจทย์ข้อสอบ:** กำหนดกราฟ $V=\{A,B,C,D\}, E=\{(A,B),(B,C),(C,D),(D,A)\}$ จงเขียน Path จากจุดยอด $A$ ไปยัง $C$
- ❌ **คำตอบที่ได้ 0 คะแนน:** `$A \rightarrow B \rightarrow C$` หรือ `$A \to B \to C$`
- ✅ **คำตอบที่ได้คะแนนเต็ม:** `$A, B, C$` หรือ `(A, B, C)`
- **เหตุผลทางวิชาการ:** ตามนิยามคณิตศาสตร์ Path คือ **Sequence of vertices** (ลำดับของจุดยอดคั่นด้วยเครื่องหมายจุลภาค) การเขียนลูกศรแสดงถึงความไม่เข้าใจนิยามพื้นฐานทางคณิตศาสตร์ อาจารย์จะให้ 0 คะแนนทันทีโดยไม่ตรวจต่อ

### กับดักที่ 2: การตอบจำนวนเส้นของ Complete Graph
- **โจทย์ข้อสอบ:** กำหนด Undirected Complete Graph ที่มี 10 Vertices จงหาจำนวนเส้นเชื่อม (Edges) ทั้งหมด
- ❌ **คำตอบที่ได้ 0 คะแนน:** ตอบติดสูตร เช่น `10*(10-1)/2` หรือ `90/2`
- ✅ **คำตอบที่ได้คะแนนเต็ม:** ตอบเป็นตัวเลขจำนวนเต็ม **`45`** หรือ **`45 เส้น`**
- **สูตรลัด:**
  $$E = \frac{V(V-1)}{2} = \frac{10 \times 9}{2} = 45$$

### กับดักที่ 3: คำถามบนกราฟว่าง (Null Graph / Empty Graph)
- **โจทย์ข้อสอบ:** กำหนดกราฟว่าง $V = \{\}, E = \{\}$ จงเขียน Path จากจุด $A$ ไปยังจุด $C$
- ❌ **คำตอบที่ผิด:** ตอบว่า $A, C$ หรือเว้นว่างไว้
- ✅ **คำตอบที่ถูกต้อง:** **"ไม่มี Path จาก $A$ ไปยัง $C$ เนื่องจากไม่มี Vertex $A$ และไม่มี Vertex $C$ อยู่ในกราฟ"**

### กับดักที่ 4: หน่วยของความยาวเส้นทาง (Length of Path)
- **นิยาม:** จำนวนเส้นเชื่อมที่อยู่บนเส้นทาง ($N - 1$ เมื่อมีจุดยอด $N$ จุด)
- ❌ **คำตอบที่ได้ 0 คะแนน:** ตอบเป็นหน่วยวัดความยาว เช่น "2 นิ้ว", "5 ซม."
- ✅ **คำตอบที่ถูกต้อง:** ตอบเป็นจำนวนเส้น เช่น **`2`** หรือ **`2 เส้น`**

## 2. การคำนวณขนาดหน่วยความจำและเปอร์เซ็นต์ความสิ้นเปลือง (Memory Calculations)

### 2.1 Adjacency Matrix Memory Waste Calculation
กำหนดกราฟมี 7 จุดยอด และมี 12 เส้นเชื่อม (แสดงในภาพ `IMG_20260923_110059` และ `IMG_20260923_110522`):
- ตาราง 2D Array ขนาด $|V| \times |V| = 7 \times 7 = \mathbf{49\text{ ช่อง}}$
- ช่องที่มีค่าเป็น 1 (แทนการมีอยู่ของ Edge 12 เส้น) มี **12 ช่อง**
- ช่องที่มีค่าเป็น 0 (ไม่ได้ใช้งาน / สิ้นเปลือง) มี $49 - 12 = \mathbf{37\text{ ช่อง}}$

#### คำถามข้อสอบภาษาอังกฤษ:
> **Question:** *"What percentage of the memory space is used for entries with a value of 1, and what percentage is used for entries with a value of 0?"*
> 
> **Calculation:**
> - ช่องที่มีข้อมูล (Value 1):
>   $$\frac{12 \times 100}{49} = \mathbf{24.48\%}$$
> - ช่องที่สิ้นเปลือง (Value 0):
>   $$\frac{37 \times 100}{49} = 100\% - 24.48\% = \mathbf{75.51\%}$$

### 2.2 การเปรียบเทียบขนาดหน่วยความจำ (Direct Graph: 10 Vertices, 20 Edges)
(ปรากฏในสไลด์และลายมืออาจารย์ `IMG_20260923_113450` และ `IMG_20260923_113807`)

| โครงสร้างข้อมูล | สูตรการคำนวณ | แทนค่าคำนวณ | หน่วยความจำที่ใช้ |
| :--- | :--- | :--- | :---: |
| **Adjacency Matrix** | Space $= \|V\|^2$ | $10^2$ | **100 ช่อง** |
| **Adjacency List** | Space $= O(\|E\| + \|V\|)$ | $20 + 10$ | **30 ช่อง** |

> **ข้อสรุปสำหรับการสอบ:** Adjacency List ช่วยประหยัดพื้นที่หน่วยความจำในกรณีนี้ได้ถึง **70%** จึงเป็นโครงสร้างที่เหมาะสมที่สุดสำหรับ Sparse Graph

## 3. ชุดจำลองข้อสอบปลายภาค (Simulated Exam Practice Set)

### ข้อที่ 1 (อัตนัย - 5 คะแนน)
กำหนดกราฟมีทิศทาง (Directed Graph) ประกอบด้วย:
- $V = \{1, 2, 3, 4, 5\}$
- $E = \{(1, 2), (1, 3), (2, 4), (3, 4), (4, 5)\}$
1. จงเขียน Path จากจุดยอด 1 ไปยังจุดยอด 5:
   - **เฉลย:** ตอบได้ 2 ทาง คือ `1, 2, 4, 5` หรือ `1, 3, 4, 5` (ห้ามใส่เครื่องหมาย $\rightarrow$)
2. ความยาว (Length) ของ Path ดังกล่าวเท่ากับเท่าใด:
   - **เฉลย:** `3` หรือ `3 เส้น`
3. กราฟนี้มี Cycle หรือไม่:
   - **เฉลย:** `ไม่มี` (กราฟนี้จัดเป็น Directed Acyclic Graph: DAG)

### ข้อที่ 2 (คำนวณพื้นที่ - 5 คะแนน)
กำหนด Directed Graph ขนาด 15 Vertices และ 25 Edges:
1. หากแทนด้วย Adjacency Matrix จะต้องใช้พื้นที่กี่ช่อง?
   - **เฉลย:** $15^2 = \mathbf{225\text{ ช่อง}}$
2. หากแทนด้วย Adjacency List จะต้องใช้พื้นที่อย่างมากไม่เกินกี่ช่อง?
   - **เฉลย:** $15 + 25 = \mathbf{40\text{ ช่อง}}$
3. อัตราส่วนความสิ้นเปลืองเนื้อที่ของ Adjacency Matrix (เปอร์เซ็นต์ช่องที่เป็น 0) มีค่าเท่าใด?
   - **เฉลย:** ช่องที่เป็น 1 มี 25 ช่อง $\rightarrow \frac{25 \times 100}{225} = 11.11\%$
   - ช่องที่เป็น 0 (สิ้นเปลือง) $= 100\% - 11.11\% = \mathbf{88.89\%}$
