[01:10] Selection Sort is a simple comparison-based sorting algorithm that works by dividing the input list into two parts:
1. Sorted part (ส่วนที่เรียงลำดับแล้ว)
2. Unsorted part (ส่วนที่ยังไม่ได้เรียงลำดับ)

[02:20] อัลกอริทึมจะทำซ้ำๆ คือ:
- Find the minimum element from the unsorted part (ค้นหาค่าที่น้อยที่สุดจากส่วนที่ยังไม่ได้เรียง)
- Swap it with the first element of the unsorted part (สลับค่าที่น้อยที่สุดนั้นกับสมาชิกตัวแรกของส่วนที่ยังไม่ได้เรียง)
- ทำกระบวนการนี้ซ้ำไปเรื่อยๆ จนกระทั่งทั้งลิสต์ถูกเรียงลำดับจนหมด

[03:40] ตัวอย่าง Original: [64, 25, 12, 22, 11] มี 5 ตัว
ตัวแปรสำคัญ: min_idx คือตัวชี้ตำแหน่งที่มีค่าน้อยที่สุด และ swap เกิดการสลับขึ้นกี่ที
โปรแกรมประกอบด้วย for loop ซ้อนกัน 2 ชั้น: for i in range(n) และ for j in range(i + 1, n)

[14:15] ⭐ ทำความเข้าใจฟังก์ชัน range() เชิงลึก:
- ใน Python range(5) จะสร้างลำดับตัวเลข 0, 1, 2, 3, 4 (ไม่ถึง 5 เพราะ stop - 1)
- range(start, stop, step) ถ้าไม่ระบุ step เป็น 1 เสมอ
- คำถามข้อสอบ: range(0) มีค่าเป็น None หรือ [0] หรือไม่?
  ตอบ: ไม่ใช่ทั้งคู่! range(0) คือลำดับว่างเปล่า (Empty sequence)
- range(0) ต่างกับ [] (Empty List) อย่างไรในเชิง Data Structure?
  ตอบ: [] จะทำการจองพื้นที่หน่วยความจำสำหรับ List Object แต่ range(0) เป็น generator/range object ที่เก็บแค่ metadata (start=0, stop=0, step=1) ไม่ได้จองหน่วยความจำเพื่อเก็บตัวเลข

[18:00] การทำงานของ for j in range(i + 1, n):
- ใน Selection Sort หมายถึงการให้ j วิ่งสำรวจสมาชิกใน Unsorted Part ถัดจากตำแหน่ง i ไปจนถึงตัวสุดท้ายขวามือสุด เพื่อหาตัวที่น้อยที่สุด (min_idx) แล้วนำมาสลับกับตำแหน่งแรกของ Unsorted Part (ตำแหน่ง i)

[21:10] หัวข้อที่ 3: Bubble Sort (การเรียงลำดับแบบฟองสบู่)
- หลักการของ Bubble Sort: หยิบตัวเลขทีละคู่ที่อยู่ติดกัน (Adjacent pairs) มาเปรียบเทียบกัน โดยวิ่งจากซ้ายไปขวา
- ถ้าตัวซ้ายมากกว่าตัวขวา ให้ทำการ Swap (สลับที่)
- ค่าที่มากที่สุดจะค่อยๆ ลอย (Bubble up) ไปอยู่ตำแหน่งขวามือสุดของอะเรย์ในแต่ละรอบ
- จำนวนรอบ (Passes / Outer loop): เท่ากับ N - 1 รอบเสมอ!

[23:30] ตัวอย่าง Tracing: [5, 1, 4, 2, 8] (5 ตัว -> ทำงาน 4 รอบ):
- รอบที่ 1:
  - คู่ที่ 1: (5, 1) -> 5 > 1 ทำการ Swap -> [1, 5, 4, 2, 8]
  - คู่ที่ 2: (5, 4) -> 5 > 4 ทำการ Swap -> [1, 4, 5, 2, 8]
  - คู่ที่ 3: (5, 2) -> 5 > 2 ทำการ Swap -> [1, 4, 2, 5, 8]
  - คู่ที่ 4: (5, 8) -> 5 < 8 ไม่ Swap
  - สิ้นสุดรอบที่ 1: ได้เลข 8 ลอยไปอยู่ขวาสุด ผลลัพธ์คือ [1, 4, 2, 5, 8] (เกิด Swap 3 ครั้ง)
- รอบที่ 2:
  - คู่ที่ 1: (1, 4) -> ไม่ Swap
  - คู่ที่ 2: (4, 2) -> Swap -> [1, 2, 4, 5, 8]
  - คู่ที่ 3: (4, 5) -> ไม่ Swap
  - สิ้นสุดรอบที่ 2: ได้เลข 5 ลอยไปอยู่ตำแหน่งรองสุดท้าย
- รอบที่ 3 & 4: ไม่มี Swap เพิ่มเติม ข้อมูลเรียงเรียบร้อย

[26:50] ⭐ วิธีลัดการหา Total Swaps ใน Bubble Sort (Inversion Counting):
- ใน Bubble Sort การสลับที่ 1 ครั้ง เกิดขึ้นเพื่อกำจัด Inversion 1 คู่
- Inversion คือคู่ตัวเลขที่ตัวหน้ามากกว่าตัวหลัง (วางผิดลำดับ)
- วิธีนับ: หยิบตัวเลขแต่ละตัว แล้วนับว่ามีตัวเลขทางขวามือของมันที่น้อยกว่ามันกี่ตัว!
- ตัวอย่าง [5, 1, 4, 2, 8]:
  - เลข 5: มี 1, 4, 2 ที่น้อยกว่า -> นับ 3
  - เลข 1: ไม่มี -> นับ 0
  - เลข 4: มี 2 ที่น้อยกว่า -> นับ 1
  - เลข 2: ไม่มี -> นับ 0
  - เลข 8: ไม่มี -> นับ 0
  - รวม Inversions = 3 + 0 + 1 + 0 + 0 = 4 คู่
  - ดังนั้น Total Swaps ทั้งหมดตั้งแต่เริ่มจนจบจะต้องเท่ากับ 4 ครั้งแน่นอน 100%!
