ในการประมวลผล เราต้องการโครงสร้างข้อมูลตาราง (Table) สำหรับเก็บสถานะของแต่ละ Vertex
ตารางนี้จะมี 3 คอลัมน์หลักสำหรับแต่ละ Vertex v:

อาจารย์: "มาดูขั้นตอนวิธี (Algorithm) แบบละเอียด:
โค้ดมันเป็นแบบนี้นะครับ ดูบนหน้าจอ:
```python
while not Q.isEmpty():
    v = Q.dequeue()
    v.known = True
    for w in v.adjacent:
        if w.dist == 999: # infinity
            w.dist = v.dist + 1
            w.path = v
            Q.enqueue(w)
```
ดูทีละบรรทัดนะครับ:
ดึง v ออกมาจาก Queue
เปลี่ยนสถานะ v.known ให้เป็น True
จากนั้น วนลูป for แต่ละ w ที่เป็น Neighbor ติดกับ v:
ถ้า w.dist ยังเป็น 999 (คือยังไม่เคยถูกเยี่ยมชม):
เราอัปเดตระยะทางของ w ให้เป็น w.dist = v.dist + 1
และบันทึกว่า w มาจากใคร โดยกำหนด w.path = v
จากนั้น enqueue w เข้าไปใน Queue Q
ทำแบบนี้ไปเรื่อยๆ จนกระทั่ง Queue ว่างเปล่า"

   มีชุดตัวเลขมาให้, คำนวณ Hash Function, การชน (Collision Resolution) ทั้ง Linear Probing, Quadratic Probing, Double Hashing, Separate Chaining, การคำนวณ Load Factor (เปอร์เซ็นต์ความจุของตาราง)
2. Binary Heap:
   มีตัวเลขมาให้, แสดงการ Insert และ DeleteMin, การแทนที่ Heap ใน Array (สูตรพ่อลูก 2i, 2i+1, i//2), การทำ BuildHeap
3. Insertion Sort:
   มีชุดตัวเลขมาให้, ให้ไล่ทีละ Pass (Pass p = 1, 2, ...), ถามว่าหลังจบลูป Pass ที่กำหนด อาร์เรย์มีค่าเป็นอย่างไร, เปรียบเทียบกี่ครั้ง, ย้ายกี่ครั้ง
4. Selection Sort หรือ Bubble Sort:
   อาจารย์จะเลือกมา 1 อัน ระหว่าง Selection Sort กับ Bubble Sort, ให้ชุดตัวเลขมาแล้วให้ไล่ Tracing เหมือน Test Program 2
5. Topological Sort:
   กราฟมีทิศทาง, คำนวณ Indegree, ใช้ Queue ไล่หา Topological Ordering
6. Unweighted Shortest Path:
   เหมือน Assignment 4 ที่ทำวันนี้เลย! ให้กราฟมา แล้วให้ตาราง Known, Dist, Path และ Queue มา ให้คุณไล่ขีดฆ่าเติมค่าทีละสเต็ป แล้วตอบระยะทางและเส้นทาง
7. คำถามย่อยๆ หลายข้อ (ข้อละ 1-3 คะแนน รวมกันประมาณ 10 คะแนน):
   - ถาม Properties: โครงสร้างข้อมูลอะไรเอ่ยที่มี 2 properties, 3 properties (เช่น Binary Heap มี 2 properties คือ Structure Property [Complete Binary Tree] และ Heap Order Property; BST มี BST Property เป็นต้น)
   - พวกที่มีการคำนวณ ใช้สูตร เปอร์เซ็นต์ what percentage of, how many เช่น:
     - Memory waste ใน Adjacency Matrix เสียพื้นที่เปล่ากี่เปอร์เซ็นต์ (จำได้ไหม ที่เราคำนวณ 24.48% กับ 75.51%)
     - จำนวนเส้นเชื่อมใน Complete Graph มีกี่เส้น: n(n-1)/2
     - จำนวนโหนดสูงสุดใน Binary Tree ที่มีความสูง h: 2^(h+1) - 1
     - สูตรหาตำแหน่ง Parent และ Child ใน Binary Heap: Left Child = 2i, Right Child = 2i+1, Parent = floor(i/2)
