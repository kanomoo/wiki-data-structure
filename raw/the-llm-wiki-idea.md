# The LLM Wiki Idea

The LLM Wiki is a pattern for building personal knowledge bases using LLMs. Instead of traditional RAG, the LLM incrementally builds and maintains a persistent, interlinked collection of markdown files.

Key concepts:
- **Persistent artifact**: The wiki compounds over time.
- **LLM-Owned**: The LLM handles summarization, cross-referencing, and bookkeeping.
- **Obsidian Integration**: The wiki is a directory of markdown files, ideal for use with Obsidian.
- **Three Layers**: Raw sources, The Wiki, and The Schema (GEMINI.md).
- **Core Files**: index.md (content catalog) and log.md (chronological log).
